# Agent instructions

Cairn is a registry of proven feature intentions: every feature is a **stone**
(`.cairn/stones/<ulid>.md`, the promise in the user's language) backed by a
Playwright **proof** (`.cairn/proofs/<ulid>.spec.ts`). See
[docs/technical.md](docs/technical.md) for the design.

## Skills

Three skills drive the loop. The canonical source is
[`.claude/skills/`](.claude/skills); they are mirrored verbatim for Codex in
[`.codex/skills/`](.codex/skills) (symlinks) and for Cursor in
[`.cursor/rules/`](.cursor/rules) (generated by
[`scripts/sync-skills.sh`](scripts/sync-skills.sh)). If your agent reads none of
those locations, read the SKILL.md directly and follow it:

| Skill | When to apply | Instructions |
| --- | --- | --- |
| **cairn-mason** | A user asks for a feature or a behaviour change ("je veux pouvoir…", "users should be able to…"). Turns the request into draft stones via `cairn add --json`; refuses refactoring, styling, tech debt and tooling. | [.claude/skills/cairn-mason/SKILL.md](.claude/skills/cairn-mason/SKILL.md) |
| **cairn-warden** | A draft stone needs its proof, or a broken stone must be re-proven. Writes the Playwright proof blind to the application source, from the running app only. | [.claude/skills/cairn-warden/SKILL.md](.claude/skills/cairn-warden/SKILL.md) |
| **cairn-triage** | `cairn verify` is red on a proven stone in CI. Classifies it: real regression (report to the coder) or legitimate intent change (draft an amendment for a human). Never edits code or proofs. | [.claude/skills/cairn-triage/SKILL.md](.claude/skills/cairn-triage/SKILL.md) |

Hard rules that apply to every agent, in every role: acceptance criteria are
user language (the CLI lints them, exit code `2`, never `--force`); the warden
never reads application source; proofs, once green, are frozen (sha256-stamped);
stones are amended, never edited.

## Editing the skills

Edit only `.claude/skills/*/SKILL.md`, then run `scripts/sync-skills.sh` to
regenerate the Cursor rules. Never edit `.cursor/rules/*.mdc` by hand — they are
overwritten.

## Development

Node 22, pnpm 10, TypeScript ESM strict.

```sh
pnpm install
pnpm -r build      # build core and cli first: cli resolves core through its dist types
pnpm -r typecheck
pnpm -r test
```
